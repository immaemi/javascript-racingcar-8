# javascript-racingcar-precourse
우아한테크코스 2주 차 프리코스 "자동차 경주"

---

## 1. 게임 설정 및 입력 처리

사용자로부터 게임에 참여할 자동차 이름과 총 이동할 횟수를 입력받고, 입력 값의 유효성을 검증한다.

### 1-1. 자동차 이름 입력 및 유효성 검사

- **입력 형식:** 자동차 이름은 쉼표(`,`)를 기준으로 구분하여 입력받는다.  
- **제한 조건:**
  - 각 자동차 이름은 **5자 이하**만 허용한다.  
  - **빈 문자열("")** 또는 공백으로만 구성된 이름은 허용하지 않는다.  
  - **중복된 이름**은 허용하지 않는다. 

### 1-2. 이동 횟수 입력

- **입력 형식:** 사용자는 몇 번의 이동(시도)을 할 것인지 **숫자**로 입력한다.  
- **유효성 검사:** 입력 값은 **1 이상의 양의 정수**여야 하며 소수는 허용하지 않는다.

---

## 2. 자동차 이동 로직

주어진 이동 횟수 동안 각 자동차의 전진 여부를 결정한다.

### 2-1. 무작위 값 생성

- 각 이동 시도마다 **0부터 9 사이의 무작위 값**을 생성한다.

### 2-2. 전진 조건

- 무작위 값이 **4 이상**일 경우, 해당 자동차는 **전진한다.**  
- 무작위 값이 **3 이하**일 경우, 해당 자동차는 **멈춘다.**

---

## 3. 게임 진행 및 결과 출력

매 턴의 진행 상황과 게임 종료 후 최종 우승자를 출력한다.

### 3-1. 이동 상태 출력

- 각 이동 시도(턴)가 끝날 때마다 현재까지의 자동차별 전진 상태를 출력한다.  
- 출력 시 자동차의 이름과 함께 전진 거리를 하이픈(`-`)으로 시각화한다.
- 예시: pobi : ---

### 3-2. 최종 우승자 결정 및 출력

- 모든 이동이 완료된 후 가장 멀리 전진한 자동차를 **우승자**로 결정한다.  
- 우승자가 여러 명일 경우 쉼표(`,`)로 구분하여 출력한다.
- 예시 : 최종 우승자 : pobi, woni

---

## 4. 오류 및 예외 처리

사용자 입력 값에 문제가 있을 경우 애플리케이션이 안전하게 종료되도록 보장한다.

### 4-1. 공통 오류 처리 규칙

- 사용자 입력이 유효하지 않은 경우, 즉시 **Error를 발생**시키고 프로그램을 종료한다.  
- 발생하는 Error 메시지는 반드시 `[ERROR]`로 시작해야 한다.

### 4-2. 구체적인 입력 오류 발생 조건

- 자동차 이름이 **5자를 초과**하는 경우  
- 자동차 이름 입력에 **쉼표(,)** 외의 부적절한 구분자가 포함된 경우  
- 시도할 횟수가 **숫자가 아닌 경우**  (예: `a`, `삼`)
- 시도할 횟수가 **음수이거나 소수**인 경우  
- 자동차 이름 또는 이동 횟수가 **빈 값이거나 null**인 경우
- **중복된 자동차 이름**이 포함된 경우
